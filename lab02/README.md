# Лабораторная работа 02

## Базовый конвейер анализа данных в Pandas

**ФИО:** Ушакова Марина Михайловна
**Группа:** ЕТ-212

## Содержание

В работе выполнены следующие этапы:

– формирование и сохранение исходных данных в формате CSV;
– загрузка данных из CSV-файла;
– проверка структуры и качества данных (поиск пропусков);
– выборка и фильтрация данных;
– расчёт описательных статистик (среднее, медиана);
– группировка данных по каналам продаж;
– формирование производного признака `is_high_value`;
– построение гистограммы распределения суммы заказов;
– формулировка итогового аналитического вывода.
